Это не противоречие, потому что Environment.ProcessorCount показывает количество логических процессоров, а не физических ядер.

# Контрольные вопросы

1. Environment.ProcessorCount показывает количество логических процессоров, которые видит операционная система.

2. Физическое ядро - это реальное ядро процессора.
Логический процессор - это виртульный поток.
3. Потому что при увеличении количества потоков, начинают работать новые ядра. Чем больше ядер работает, тем больше загружен CPU.
4. Потому что загрузка упирается в физический потолок в 100%.
5. Для ускорения работы.
